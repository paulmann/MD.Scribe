# MD.Scribe — agent instructions

MD.Scribe is a self-hosted, framework-free, database-free PHP 8.5 Markdown documentation platform
(MIT, 3.6.2 "Colophon"). This file is the agent's map: the commands that must pass, the invariants
that must not break, the traps that have already bitten this project, and where the detail lives.
The deep reference is [docs/AGENTS-context.md](docs/AGENTS-context.md); read the layer you are changing.

Verified against the tree on 2026-11-14: `Version::VERSION = '3.6.2'`, `CODENAME = 'Colophon'`,
`PHP_MIN = '8.5.0'`; `composer.json` requires `php >= 8.5`; CI runs PHP 8.5 only (`php: ['8.5']`).
Release `v3.6.2`; tags `v3.1.0`, `v3.2.0`, `v3.2.1`, `v3.4.4`, `v3.5.0`, `v3.6.0`, `v3.6.1`, `v3.6.2`.

## Commands

```powershell
# install (COMPOSER_HOME is required when APPDATA is unset)
$env:COMPOSER_HOME = Join-Path ([System.IO.Path]::GetTempPath()) 'composer-home'
composer install
# the gates CI runs
composer test        # PHPUnit: 236 tests, 846 assertions
composer stan        # PHPStan level 6
Get-ChildItem src,public,templates,tools,tests -Recurse -Filter *.php | ForEach-Object { php -l $_.FullName }
php -l md.php; php -l index.php; php -l updater.php
cd tools/frontend; npm ci; node build.mjs --vendor   # outputs incl. vendor bundles are committed
# browser gate: diagrams, KaTeX, icons, CSP, table layout (needs the dev server above)
node tools/frontend/check-render.mjs --base=http://127.0.0.1:8099
# release artifact: digest, manifest, a booted copy, six routes, browser gate
php tools/verify-release.php --version=<version>
# local dev server and the read-only doctrine checker (12 checks)
php -S 127.0.0.1:8099 -t public public/router.php
pwsh -File tools/Invoke-ProjectDoctrine.ps1
```

CI runs the same gates on Ubuntu, plus a smoke run (home, `?page=browser`, `?page=themes`, `?api=search`,
and a 404). The `assets` job rebuilds the frontend **with `--vendor`** and fails on any drift from the
committed `public/assets` or `src/View/Icons.php`; the `render` job drives a real browser
(`tools/frontend/check-render.mjs`, puppeteer-core on the system Chrome) because the failures that
reached main — a repair that never reached the renderer, an empty icon after a vendor rebuild — are
invisible to PHPUnit.

## Non-negotiable rules

1. **PHP 8.5 is the floor, not a target.** `Version::PHP_MIN = '8.5.0'`, `composer.json` requires `>=8.5`,
   and `src/bootstrap.php` answers HTTP 500 below it; CI runs 8.5 only. Never lower the floor or patch the gate.
2. **One path validator.** Every request value reaches the filesystem only through
   `MdViewer\Files\PathValidator`; no `realpath()`, no `basename()`, no hand-rolled traversal check.
3. **Writes are atomic; deletes are soft.** Temp file + `LOCK_EX` + `chmod 0644` + `rename`
   (`src/Files/FileManager.php:370-387`); deletes move to `storage/backups/trash/`. Never rewrite in place.
4. **Escape on output; sanitize with an allowlist.** Templates use `e()`, JSON goes through `Response::json`,
   inline scripts carry the CSP nonce, and every render passes `HtmlSanitizer`. A new tag, attribute or
   `data-*` reaches the browser only after it is allowlisted; the `id` regex is Unicode on purpose
   (`/^[\p{L}\p{N}][\p{L}\p{N}_:.\-]{0,96}$/u`).
5. **Cache correctness is correctness.** The render-cache key carries `Version::VERSION`, the feature
   fingerprint and the corpus stamp; a rendering change without a version bump serves yesterday's HTML.
6. **Admin mutations are POST + CSRF + authenticated,** applied centrally by `AdminKernel`
   (`src/Http/AdminKernel.php:57-65`); do not add a route in front of it.
7. **Strict types and the PHPStan ratchet:** `declare(strict_types=1)` in every `src/` file, PHPStan level 6,
   no new `ignoreErrors` (`phpstan.neon:33-34`).
8. **Version = CHANGELOG = README.** All three move in one commit (the doctrine checker compares them);
   `config/manifest.json` is generated by `tools/build-manifest.php`, never hand-edited.
9. **No secrets, no CDN, no hand-edited outputs.** No keys/tokens/passwords in the tree; `.md.ini` is never
   served (docroot `public/` is the safe layout); every asset is local (CSP `default-src 'self'`);
   built frontend assets are committed and changed only through `tools/frontend`.
10. **One logical change per commit:** conventional imperative subject, the why in the body, no drive-by
    reformatting.

## Traps

| Trap | Evidence | Consequence |
|---|---|---|
| The render-cache key uses the version string, not a code hash | `src/Markdown/RenderCache.php:39-42` | A renderer edit without a version bump is invisible to readers and to the cache |
| The sanitizer silently deletes what it does not recognise | `src/Markdown/HtmlSanitizer.php:41-109` | Unit tests pass, the browser path loses the attribute |
| `ALLOW_IFRAMES` and `ALLOW_EXTERNAL_IMAGES` are outside the fingerprint | `src/Markdown/MarkdownEngine.php:185` | Toggle them, then clear the cache, or old HTML keeps the old policy |
| An admin page slug is registered in four places | `src/Http/AdminKernel.php:103,404,417,436` | A missed one renders the dashboard instead of an error |
| The corpus stamp is path + mtime + size | `src/Files/CorpusStamp.php:20-32` | A same-size edit inside the same second is not indexed; rebuild from Tools |
| The manifest is a release artefact and goes stale silently | `config/manifest.json`, `tools/build-manifest.php` | `status()` reports every later file as `modified`; the updater refuses on the first mismatch |
| A `types { }` block in nginx replaces the whole MIME table | measured on the deployment host (nginx 1.24) | Every `.css`/`.js`/`.svg` becomes octet-stream; map one extension with `location ~ \.webmanifest$` |
| A dry run that compares local files with the local manifest says "nothing to replace" | `src/Admin/UpdateService.php` (`plan()` vs `status()`) | It examined the wrong object; `plan()` must verify the manifest inside the downloaded archive |
| The updater needs the release archive, not a branch tarball | `src/Admin/UpdateService.php`, `docs/development.md` step 8 | A branch tarball never contains `vendor/`, so it can never satisfy the manifest |
| PHPStan does not see `bin/`, `tools/` or `templates/` | `phpstan.neon:3-9` | A syntax error there passes analysis; `bin/` is not linted by CI either |
| The browser half of the pipeline is only checked by hand | `tools/frontend/check-render.mjs` (CI job `render`) | A repair, an icon or a CSP regression passes every PHP test and reaches main |
| A deploy from `git archive` has no `vendor/` | `tools/deploy/mdscribe-deploy` (staged check) | `rsync --delete` removes 731 files and every page is a PHP fatal |
| opcache caches by the path it was given, not the symlink target | measured on the host: `…/mdscribe/public/index.php` cached with `ts=0` | The symlink points at the new release and the old code keeps running; `systemctl reload` does not clear it |
| `config/manifest.json` is excluded from its own file list | `tools/build-manifest.php` (`$excludeFiles`) | An updater that swaps only manifest entries leaves the manifest stale and every later status reports the new files as modified |
| The backup/restore loop sees native path separators | `src/Admin/UpdateService.php` (`restoreApp`) | `config/manifest.json` failed the `/`-only allowlist and every nested file was silently skipped on Windows |
| A `zipfile` archive carries no POSIX modes | measured: `0666` on every deployed file | Application code writable by any local account |
| Tailwind v4 scans the whole repository unless told otherwise | `tools/frontend/src/css/app.css` (`source(none)`) | A word like "invisible" in a changelog entry added a utility to the committed CSS, so a prose edit changed the bundle |

## Machine APIs

- **Render:** `POST /index.php?api=render` with `X-Api-Key` and JSON
  `{"content": "...", "format": "auto|markdown|html|text"}` → `{ok, data: {html, bytes, elapsed_ms}}`.
  `html` is a fragment; `401 bad_key`, `422 empty_content|bad_format`, `413 too_large`. Without a key
  the legacy session+CSRF clipboard contract applies.
- **Admin JSON:** `admin.php?action=verb.noun`, session auth + CSRF; `401`, `403` CSRF/flag, `409`, `413`.
- **Updater:** `updater.php?api_key=...&action=status|conflicts&format=json`; `install&dry_run=1`
  reports what would change and writes nothing.

## Verify before claiming done

```powershell
composer test                                # 236 tests, 846 assertions, exit 0
composer stan                                # no errors at level 6
pwsh -File tools/Invoke-ProjectDoctrine.ps1  # checks: 12, errors: 0, warnings: 0, PASS
Get-ChildItem src,public,templates,tools,tests -Recurse -Filter *.php | ForEach-Object { php -l $_.FullName }
# with the dev server running: diagrams, KaTeX, icons, CSP, table layout in a real browser
node tools/frontend/check-render.mjs --base=http://127.0.0.1:8099   # 21 checks, exit 0
# after publishing: the artifact and a booted copy of it
php tools/verify-release.php --version=<version>                    # 17 checks, exit 0
```

For a request-path change, also start the dev server and check `/`, `?page=browser`, `?page=themes`,
`?api=search&q=markdown` (expect `"ok":true`) and `?file=nope.md` (expect 404). Say which commands you
could not run; a green suite that examined nothing is a failure.

## Do not

- Do not lower the PHP floor, patch the 8.5 bootstrap gate, or claim support for older PHP.
- Do not add a second path validator or bypass `FileManager` for writes and deletes.
- Do not add a tag, attribute or `data-*` to the sanitizer without a regression test.
- Do not ship a static `manifest.webmanifest` link (use `?api=manifest`) or any CDN asset.
- Do not edit `public/assets/` by hand, or commit `vendor/`, `storage/`, `.md.ini` or secrets.
- Do not run `updater.php?update=true` or `?restore=...` to see what happens; take a backup first.
- Do not mix formatting churn with a behaviour change, commit without running the verify block, or
  report a check you did not run.
